## Данные
Датасеты доступны на [Kaggle: NYC Apartment Listings](https://www.kaggle.com/competitions/two-sigma-connect-rental-listing-inquiries/data).

Поместите файлы `train.json` и `test.json` в папку `data/` перед запуском ноутбуков.


# Активируйте своё окружение
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

# Сохраните зависимости
pip freeze > requirements.txt
